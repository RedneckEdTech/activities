Key Calculus Insights

  • • When original curve has a horizontal tangent (flat peak/trough), $f'(x) = 0$ (crosses the horizontal axis).
  • • When $f(x)$ is increasing (slanted up), $f'(x) > 0$ (above horizontal axis).
  • • When $f(x)$ is decreasing, $f'(x) < 0$ (below horizontal axis).

The 5-Step Optimization Process

1. Objective Function
$V(x) = x(12-2x)(18-2x)$
2. First Derivative $\frac{df}{dx}$
$V'(x) = 12x^2 - 120x + 216$
3. Set $f'(x) = 0$ (Critical Points)
$x \approx 2.35 \text{ cm}$ (in physical domain)
4. Second Derivative Test
$V''(2.35) = -63.6 < 0 \implies \text{Concave Down (Maximum!)}$
5. Evaluated Value at Current $x$
$V(2.00) = 224.00 \text{ cm}^3$
